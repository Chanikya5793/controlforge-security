ControlForge 0.5.0 public pilot
================================

Availability
------------
This is a controlled staging pilot for Apple Silicon Macs running macOS 13 or
newer. It is not a general-availability or enterprise-SLA release.

What changed
------------
- Delivery and action polling now use independent, persistent retry circuits.
- Network failures are redacted before they reach status or spool records.
- Raw Santa telemetry remains durable while unchanged control snapshots coalesce.
- Each collection cycle has a bounded backlog flush limit.
- The cloud service adds tenant and device ingestion budgets, a storage high-water
  stop, selective telemetry retention, bounded direct-D1 recovery, and atomic
  audit-coupled security mutations.

Important pilot boundaries
--------------------------
- The package connects to the staging account service, not a production SLA.
- A network administrator must provide an endpoint account.
- Santa and its required macOS approvals remain separate prerequisites.
- Clean-Mac install, reboot, upgrade, rollback, and uninstall acceptance is not
  yet complete. Start with a non-critical test Mac.
- Automated containment remains fail-closed and is not enabled by this package.
